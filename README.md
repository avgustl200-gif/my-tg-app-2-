# Магазин в Telegram (Mini App) — Vapeliquid

Витрина с категориями, вкусами и остатками, корзина, оформление заказа (телефон, город, адрес, Telegram username, комментарий), промокоды, лояльность («каждая N-я покупка со скидкой»), админ-панель прямо в приложении, уведомления о заказах в Telegram. Цвета — из логотипа (тёмно-синий, электрический синий, зелёный). Только Python 3.9+ — **ничего устанавливать не нужно**.

## Запуск за 10 минут

1. **Создайте бота:** в Telegram откройте @BotFather → `/newbot` → получите токен. Узнайте свой ID у @userinfobot.
2. **Настройте:** `cp .env.example .env`, впишите `BOT_TOKEN`, `ADMIN_IDS`, `PUBLIC_URL`.
3. **HTTPS обязателен** (Telegram не открывает http). Варианты: сервер с доменом + Caddy (`deploy-Caddyfile`), либо для теста — Cloudflare Tunnel / ngrok, адрес вписать в `PUBLIC_URL`.
4. **Запустите:** `python3 run.py --seed` (первый раз — добавит демо-товары; потом просто `python3 run.py`). Автозапуск на сервере — `deploy-shop.service`.
5. В @BotFather: `/mybots` → ваш бот → Bot Settings → Menu Button (или Configure Mini App) → укажите `PUBLIC_URL`. Бот также сам ставит кнопку «Магазин» и отвечает на любое сообщение кнопкой открытия.
6. Откройте бота → «Магазин». Вкладка **Админ** видна только вам (ID из `ADMIN_IDS`).

## Что настраивается в админке (без программиста)

* **Товары:** название, фото (загрузка с телефона), цена, старая цена (появится «−20%»), ярлык NEW/SALE, описание, категория, остаток.
* **Вкусы:** у жидкостей — список вкусов со своим остатком. Вкус с остатком 0 **исчезает с витрины сам**; когда у всех вкусов 0 — исчезает товар. Вернулся остаток (или отменён заказ) — товар появляется снова.
* **Категории:** Жидкости, Картриджи, Устройства и любые другие; порядок и скрытие.
* **Промокоды:** процент или сумма, минимальный заказ, лимит применений всего и на клиента, срок, вкл/выкл.
* **Лояльность:** включить, «каждая N-я покупка» (по умолчанию 5), размер скидки (% или сумма), минимальная сумма. Клиент видит в профиле прогресс «✓ ✓ ✓ ✓ 🎁». Заказы со статусом «Отменён» не считаются. Можно выбрать: суммировать промокод и скидку лояльности или применять самую выгодную.
* **Заказы:** новые приходят вам в Telegram; в приложении — смена статуса (подтвердить → отправлен → выполнен / отменить). Клиенту уходит уведомление. Отмена возвращает товар в наличие и промокод.
* **Настройки:** название, валюта (BYN), приветствие, мин. сумма заказа, доставка и бесплатная доставка от суммы, «осталось N», окно 18+, выключатель приёма заказов, контакт поддержки.

## Безопасность (что сделано)

* Подпись Telegram `initData` проверяется на сервере (HMAC), данные старше 24 ч отклоняются. Админ-API — только для `ADMIN_IDS`.
* Цены и остатки берутся только из базы; заказ списывает остатки в одной транзакции — два клиента не купят последнюю единицу. Лимиты запросов на клиента.
* Загрузки: только PNG/JPG/WEBP/GIF до 3 МБ, проверка по содержимому, случайные имена. Весь вывод в интерфейсе экранируется (нет XSS). Заголовки CSP/nosniff.
* `DEV_MODE=1` отключает проверку подписи — **только для локальной проверки**.

## Важно

* **Окно 18+** включено по умолчанию, не выключайте. Продажа табачных и никотиносодержащих изделий регулируется законом; **требования к онлайн-торговле, рекламе и доставке в вашей стране (Беларусь) вы проверяете сами** — я не смог подтвердить действующие нормы, а в Беларуси готовятся/вводятся ограничения на онлайн-продажу и рекламу вейп-продукции. Это приложение — инструмент, юридическая ответственность на владельце магазина.
* Оплата в приложении не встроена: заказ оформляется, вы связываетесь с клиентом (наличные/перевод при получении).
* Резервная копия: файл `data/shop.db` и папка `data/uploads/` — копируйте их регулярно.

## Проверка

`python3 -m unittest discover -s tests -v` — 39 тестов (подпись Telegram, остатки и гонка двух покупателей, промокоды, лояльность, права доступа, загрузки).
Локальный просмотр без Telegram: `DEV_MODE=1 ADMIN_IDS=1 python3 run.py --seed` и откройте `http://127.0.0.1:8080/?dev=1` (админ) или `?dev=2` (клиент).
